Aquí aparecerá el código CSS del filtro calculado.

Cuanto más bajo es este número, más cerca está el resultado del color objetivo.

Si el valor de Loss sigue siendo alto, normalmente no se debe a la necesidad de recalcular el filtro, sino a algunas limitaciones del método:

  • Algunos colores son difíciles de aproximar únicamente mediante filter.
  • Partir de negro puro (#000) limita el espacio de resultados posibles.
  • La combinación de invert, sepia, saturate, hue-rotate, brightness y contrast no permite reproducir con exactitud todos los colores.
